# ⚡ Complexity Analysis

Solutions are analyzed using:

### Time Complexity

Understanding how runtime scales with input size.

Examples:

```text
O(1)
O(log n)
O(n)
O(n log n)
O(n²)
O(2ⁿ)
```

### Space Complexity

Understanding the additional memory required by an algorithm.

Whenever relevant, solutions include explicit time and space complexity analysis.
